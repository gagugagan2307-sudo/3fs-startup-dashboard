# 3FS Creative Studio — GitHub Final V6

Clean GitHub-ready website package.

## Included
- Dashboard, Projects, Clients, Teams, Services, Enquiries, Partners, Contacts
- Accounts, Bank Accounts, Project Files, Reports, Announcements, Meetings, Audit Trail, Calendar
- Working touch-friendly Projects navigation
- Tap-to-edit project/report data
- Separate Profit and Loss report fields
- Create and edit 3-Day Report Snapshots
- Team-wise 3-Day Snapshot cards
- Live Supabase persistence with realtime updates
- Anonymous Supabase authentication bridge
- Dark, colorful dashboard cards

## Supabase setup
1. Enable **Anonymous Sign-Ins** in Supabase Authentication settings.
2. Run `database.sql` in the Supabase SQL Editor.
3. Keep `supabase-config.js` in the repository root.
4. Deploy the repository with GitHub Pages.

Never add a Supabase service-role/secret key to the browser.
